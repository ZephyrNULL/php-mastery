##  Overview

**PHP Mastery** is a curated, production-oriented repository designed to explore, test, and master advanced PHP development principles, modern framework patterns, and enterprise-grade architecture. Whether you are transitioning from legacy procedural code to modern object-oriented programming (OOP) or fine-tuning your knowledge of modern PHP 8+ features, this repository serves as a practical sandbox and reference guide.

The project highlights clean code principles, SOLID design patterns, efficient database management via tools like phpMyAdmin, and secure web application development practices from scratch.

---

##  Core Features & Topics Covered

* **Modern PHP 8+ Paradigm:** Leveraging constructor promotion, match expressions, union/intersection types, attributes, fibers, and JIT-friendly patterns.
* **Object-Oriented Programming (OOP):** Deep dives into dependency injection containers, service providers, interfaces, abstract classes, and trait composition.
* **Custom Routing & Architecture:** Implementing lightweight MVC (Model-View-Controller) structures and routing engines without bloated third-party framework dependencies.
* **Database Integration:** Secure PDO implementations, prepared statements, migration management, and relational database administration patterns compatible with phpMyAdmin.
* **Security Standards:** Advanced input sanitization, output escaping, password hashing (Argon2id/Bcrypt), CSRF token protection, and secure session management.

---

##  Tech Stack

* **Language:** PHP 8.2+
* **Database Management:** MySQL / MariaDB (managed via phpMyAdmin)
* **Server Environment:** Apache 2.0 (configured via `site.php` and virtual hosts)
* **Dependency Management:** Composer
